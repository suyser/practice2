HTML: подготовка к CSS

class и id, div и span, формы, таблицы, комментарии и спецсимволы.

1. Атрибуты class и id

Атрибут это дополнительная настройка тега, она пишется внутри открывающего тега: имя="значение". Атрибуты class и id дают элементу «имя», по которому CSS находит, что оформлять.

classid
Повторяетсяда, один класс на много элементовнет, на странице только один такой id
Несколько значенийда, через пробелнет, одно значение
В CSS.note#main-title
Для чегообщий стиль группы элементовуникальный элемент, якорь для ссылки, связь с label

Правила имён: латиница, цифры, дефис и подчёркивание, без пробелов и не с цифры. Лучше называть по смыслу (price, menu-item), а не по внешнему виду (red-text).

Через id можно сделать ссылку на место страницы: <a href="#main-title"> прокрутит к элементу с таким id.

2. div и span, блочные и строчные элементы

<div> и <span> ничего не значат сами по себе и нужны, чтобы сгруппировать содержимое и повесить на него class или id.

Блочные (block)Строчные (inline)
Начинаются с новой строкиИдут в строку друг за другом
Занимают всю ширину родителяЗанимают столько места, сколько нужно содержимому
Можно задавать ширину и высотуШирину и высоту задать нельзя
div, p, h1–h6, ul, ol, li, header, main, footer, section, form, tablespan, a, b, i, u, sub, sup, img, button, input

Как это выглядит: два div идут друг под другом, два span стоят в одной строке.

div 1
div 2
span 1 span 2

Правило выбора: нужно сгруппировать целый блок, значит div. Нужно выделить кусочек внутри текста, значит span. Если подходит семантический тег (header, section и другие), берут его, а не div.

3. Формы

Форма собирает данные от пользователя. Всё лежит внутри <form>.

label

Подпись к полю. Если for у label равен id у поля, то клик по подписи ставит курсор в поле (а у флажка отмечает его). Здесь и пригождается id.

Полезные атрибуты

placeholder подсказка внутри пустого поля. name имя поля, по нему данные уходят на сервер. value значение по умолчанию. required поле обязательно. checked флажок отмечен заранее. disabled поле недоступно.

Флажки и переключатели

У переключателей одной группы одинаковый name, иначе можно будет выбрать сразу несколько.

textarea и select

textarea многострочное поле, у него есть закрывающий тег, текст между тегами станет начальным значением. select выпадающий список, каждый пункт это option.

4. Таблицы

ТегЧто это
tableвся таблица
trстрока (table row)
thячейка заголовка (жирная, по центру)
tdобычная ячейка (table data)
captionназвание таблицы
thead, tbody, tfootшапка, тело и итог таблицы

Таблица строится строками: сначала tr, внутри него ячейки. Колонок отдельным тегом нет, их количество определяется числом ячеек в строке.

Объединение ячеек: colspan="2" растягивает ячейку на две колонки, rowspan="2" на две строки.

Таблицы нужны для данных. Делать ими макет страницы нельзя, для этого есть div и CSS.

5. Комментарии и спецсимволы

Комментарии

Комментарии нужны для заметок себе и чтобы временно «выключить» кусок кода. Горячая клавиша в редакторе: Ctrl + /. Всё равно помни, что комментарий виден в исходном коде страницы любому.

Спецсимволы (HTML-сущности)

Некоторые символы нельзя написать как есть. Например, < браузер примет за начало тега. Для них есть записи вида &имя;.

ЗаписьСимволЗачем
&nbsp;неразрывный пробелнесколько пробелов подряд и пробел, где нельзя переносить строку
&copy;©знак авторского права
&lt;<показать знак «меньше» в тексте
&gt;>показать знак «больше»
&amp;&показать амперсанд
&quot;"кавычка

Обычные пробелы браузер схлопывает в один, поэтому сколько ни нажимай пробел, в тексте будет один. А &nbsp; вставляется каждый раз.
